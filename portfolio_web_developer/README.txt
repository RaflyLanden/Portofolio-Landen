PORTOFOLIO WEB DEVELOPER — PANDUAN SINGKAT

ISI FOLDER
- index.html  : struktur dan isi website
- style.css   : tampilan, warna, layout, dan responsif
- script.js   : menu mobile, animasi ringan, serta pengaturan kontak

CARA MEMBUKA
1. Ekstrak file ZIP (jika Anda mengunduh versi ZIP).
2. Buka folder portfolio_web_developer.
3. Klik dua kali index.html untuk membukanya di browser.

DATA YANG PERLU DIGANTI
1. Buka script.js dan isi bagian profile di paling atas:
   name: "Nama Lengkap Anda",
   brand: "Landen Portofolio",
   email: "alamat@email.com",
   github: "https://github.com/username-anda",
   linkedin: "https://www.linkedin.com/in/username-anda"
2. Nama akan diperbarui otomatis pada bagian hero dan footer, sedangkan brand tampil pada logo (header dan footer).
3. Simpan file, lalu refresh browser.

CATATAN ISI
- Proyek KNN/MATLAB ditulis sebagai proyek akademik/skripsi berdasarkan informasi yang telah diberikan.
- Jangan menambahkan hasil akurasi, tautan repositori, sertifikat, atau pengalaman yang belum benar-benar dimiliki.
- Bagian "More projects coming" adalah penanda bahwa proyek web tambahan belum dimasukkan. Hapus bagian tersebut setelah proyek baru tersedia.

PUBLIKASI DENGAN GITHUB PAGES
1. Buat repository baru di GitHub.
2. Unggah index.html, style.css, dan script.js ke root repository.
3. Buka Settings > Pages.
4. Pada bagian Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Setelah proses publikasi selesai, GitHub akan menampilkan alamat website pada halaman Pages.

Website ini menggunakan Google Fonts untuk tipografi. Jika internet tidak tersedia, browser akan menggunakan font cadangan.
