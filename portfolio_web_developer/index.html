01 — TENTANG SAYA

Perjalanan dimulai dari rasa ingin tahu.

Saya merupakan lulusan Program Studi Teknik Informatika dari Universitas Muslim Indonesia tahun 2026 yang memiliki ketertarikan untuk mengembangkan karier di bidang teknologi informasi, khususnya Web Development.

Selama menempuh pendidikan, saya mempelajari dasar-dasar pemrograman dan pengembangan perangkat lunak menggunakan HTML, CSS, JavaScript, TypeScript, dan PHP. Saya juga pernah menggunakan MySQL dan Firebase untuk pengelolaan basis data, serta Git dan GitHub untuk pengelolaan kode program. Selain itu, saya menggunakan MATLAB dalam proyek akademik yang berkaitan dengan pengolahan citra digital dan klasifikasi.

Saya memiliki semangat belajar, berusaha bertanggung jawab, teliti, dan terbuka terhadap hal-hal baru. Melalui kesempatan magang, saya ingin meningkatkan kemampuan teknis, memperoleh pengalaman kerja secara langsung, serta belajar berkontribusi dalam tim dan lingkungan kerja profesional.
